# راهنمای تهیهٔ فایل کاتالوگ محصولات

> ستون‌ها و قواعد زیر از روی کاتالوگ واقعی ۱۵۰ محصولی سامانه استخراج شده‌اند.
> ابزار بررسی آماده است و همین قواعد را مو به مو کنترل می‌کند.

فایل را می‌توانید در اکسل پر کنید و با فرمت **CSV با کدگذاری UTF-8** ذخیره
کنید. قالب آماده: `docs/client/catalog-template.csv`.

## ستون‌های الزامی

| ستون | معنی | نمونه | قاعده |
|---|---|---|---|
| `id` | شناسهٔ یکتا | `sofa-014` | تکراری نباشد؛ فقط حروف انگلیسی، عدد، خط تیره و زیرخط |
| `title_fa` | نام فارسی | `مبل سه‌نفره پارچه‌ای` | الزامی |
| `title_en` | نام انگلیسی | `Three-seat fabric sofa` | الزامی |
| `category` | دستهٔ کالا | `sofa` | فقط از فهرست مجاز |
| `room_type` | نوع فضا | `living_room` | فقط از فهرست مجاز |
| `price_toman` | قیمت به تومان | `24500000` | فقط عدد صحیح، بدون کاما و بدون «تومان» |
| `seller` | نام فروشنده | `دکوراسیون آرام` | الزامی |
| `seller_link` | لینک صفحهٔ محصول | `https://...` | باید با `https://` شروع شود و باز شود |
| `image_url` | نشانی تصویر | `https://...` | تصویر باید مستقیماً باز شود |
| `dimensions_cm` | ابعاد به سانتی‌متر | `220x95x85` | به ترتیب طول×عرض×ارتفاع |
| `color_palette` | کدهای رنگ | `#2D8C50,#1A1A1A` | کد رنگ ۶ رقمی، با کاما جدا شود |
| `style_tags` | سبک | `modern,minimal` | فقط از فهرست مجاز، با کاما |
| `material_tags` | جنس | `fabric,wood` | فقط از فهرست مجاز، با کاما |
| `description_for_embedding` | توصیف کوتاه | یک تا دو جمله | هرچه دقیق‌تر، پیشنهادها بهتر |

## فهرست‌های مجاز

**دسته (`category`):** `sofa` · `chair` · `coffee_table` · `rug` ·
`lighting` · `storage` · `decor`

**نوع فضا (`room_type`):** فعلاً `living_room`
_(افزودن اتاق خواب و آشپزخانه یک تصمیم باز است — بند ۶ سند راه‌اندازی.)_

**سبک (`style_tags`):** `modern` · `minimal` · `classic` · `industrial` ·
`scandinavian` · `boho`

**جنس (`material_tags`):** `wood` · `metal` · `fabric` · `leather` · `rattan`

## تبدیل از JSON

اگر کاتالوگ شما از قبل به صورت فایل JSON آماده است، لازم نیست آن را دستی در
اکسل بازنویسی کنید:

```
python scripts/catalog_json_to_csv.py my-catalog.json my-catalog.csv
python scripts/validate_catalog.py my-catalog.csv
```

قاعدهٔ تبدیل:

| در JSON | در CSV |
|---|---|
| `"dimensions_cm": {"length":220,"width":95,"height":85}` | `220x95x85` |
| `"color_palette": ["#CFCFD1","#2E2E2E"]` | `#CFCFD1,#2E2E2E` |
| `"style_tags": ["modern","minimal"]` | `modern,minimal` |
| `"material_tags": ["fabric","metal"]` | `fabric,metal` |
| بقیهٔ فیلدها | بدون تغییر |
| فیلدهای اضافی (مثل `dataset_notice`) | حذف می‌شوند |

خروجی با کدگذاری UTF-8 و BOM ذخیره می‌شود تا اکسل متن فارسی را درست نشان دهد.

## نکته‌های مهم

* **حداقل تعداد:** برای اینکه پیشنهادها معنادار باشند، دست‌کم **۵۰ محصول**
  لازم است. کاتالوگ نمایشی فعلی ۱۵۰ محصول دارد.
* **قیمت:** فقط عدد. مثلاً `۲۴٬۵۰۰٬۰۰۰ تومان` پذیرفته نمی‌شود، `24500000`
  درست است. ارقام فارسی هم به‌صورت خودکار تبدیل می‌شوند.
* **لینک فروشنده:** لینک‌های خراب توسط سامانه علامت‌گذاری می‌شوند و محصول در
  نتایج پایین‌تر می‌آید.

## بررسی فایل پیش از تحویل

```
python scripts/validate_catalog.py my-catalog.csv
```

خروجی، خطاها را با **شمارهٔ سطر اکسل** و به فارسی فهرست می‌کند. نمونهٔ خروجی:

```
[خطا] ۳ مورد — باید اصلاح شود:

  ✕ سطر ۳ · ستون «دسته»: مقدار «armchair» مجاز نیست. مقادیر مجاز: chair · ...
  ✕ سطر ۴ · ستون «قیمت»: «4,500,000 تومان» عدد صحیح نیست. فقط رقم بنویسید...
  ✕ سطر ۵ · ستون «نام فارسی»: خالی است و باید پر شود.

نتیجه: فایل آمادهٔ تحویل نیست. موارد بالا را اصلاح و دوباره اجرا کنید.
```

* **خطا** باید اصلاح شود؛ **هشدار** اجباری نیست.
* اگر همه‌چیز درست باشد پیام «فایل بدون اشکال است ✓» را می‌بینید.
* برای گزارش ماشین‌خوان: `--json report.json`

دو فایل نمونه برای مقایسه در `docs/client/fixtures/` هست: یکی سالم
(`catalog_good.csv`) و یکی پر از خطای عمدی (`catalog_broken.csv`).
