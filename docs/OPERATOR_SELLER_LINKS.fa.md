# راهنمای اپراتور: مدیریت و جایگزینی لینک‌های قرنطینه‌شده فروشندگان

**مخاطب:** تیم عملیات و پشتیبانی محتوا (Content Ops / Admin Operators)  
**نسخه سند:** ۱.۰ (مرحله ۳ تحویل)  
**سیستم:** پلتفرم هوشمند پیشنهاد دکوراسیون داخلی

---

## ۱. هدف و منطق قرنطینه (Quarantine Policy)

تمامی لینک‌های ارائه‌شده از فروشندگان (Digikala، ترب و سایر فروشگاه‌های آنلاین) جهت جلوگیری از نمایش لینک‌های نامعتبر (خطای ۴۰۴)، دامنه‌های منقضی یا خطرناک (SSRF / بدافزار) و حفظ تجربه کاربری، به صورت خودکار توسط سرویس اعتبارسنجی بررسی می‌شوند:

* **سالم (`ok`):** لینک مستقیماً با وضعیت HTTP 200 پاسخ می‌دهد.
* **تغییر مسیر (`redirect`):** لینک با موفقیت به آدرس جدید هدایت شده و سالم است (بهتر است در فرصت مناسب به‌روزرسانی شود).
* **قرنطینه / نامعتبر (`dead` / `unsafe` / `blocked`):** لینک پاسخ خطای ۴۰۴/۵۰۰ داده یا دامنه نامعتبر است. این لینک‌ها با نشان **🔴 قرنطینه** در پنل مدیریت مشخص می‌شوند.

## ۲. گردش کار اپراتور برای جایگزینی لینک (مرحله به مرحله)

### گام اول: ورود به پنل و فیلتر کردن کالاهای قرنطینه
1. با حساب مدیر وارد پنل مدیریت شوید: `/admin/products`
2. از نوار فیلتر بالای جدول، روی دکمه **«قرنطینه / نامعتبر (Quarantined)»** کلیک کنید.
3. لیست کلیه کالاهایی که لینک فروشنده آن‌ها با خطا مواجه شده است فیلتر و نمایش داده می‌شود.

### گام دوم: بررسی کالای قرنطینه و استخراج لینک جدید
1. عنوان کالا و تصویر محصول را بررسی کنید.
2. در سایت فروشگاه معتبر (مانند دیجی‌کالا)، محصول مرتبط و موجود را جستجو کنید.
3. آدرس مستقیم صفحه محصول را کپی کنید (نمونه: `https://www.digikala.com/product/dkp-XXXXXX/...`).
   * *نکته امنیتی:* آدرس باید حتماً با پروتکل `https://` آغاز شده و متعلق به فروشگاه‌های مجاز باشد.

### گام سوم: ویرایش و ثبت لینک جدید در پنل
1. در ردیف کالای مربوطه، روی دکمه **ویرایش (Edit)** کلیک کنید.
2. در پنجره ویرایش هوشمند، فیلد `"seller_link"` را با آدرس جدید جایگزین کنید.
3. پیش‌نمایش تغییرات (Diff) را بررسی کنید و دکمه **«Save changes»** را بزنید.

### گام چهارم: اعتبارسنجی خودکار
* پس از ذخیره، سیستم در پس‌زمینه (Background Task) لینک جدید را ارزیابی کرده و وضعیت کالا به **«✓ سالم»** تغییر می‌یابد.

## ۳. دستورالعمل به‌روزرسانی دسته‌جمعی دیتاست (ویژه توسعه‌دهندگان)

در صورت اصلاح دسته‌جمعی لینک‌ها در فایل دیتاست محلی:
```bash
# اعتبارسنجی لینک‌های کاتالوگ
python scripts/check_links.py

# بررسی انطباق ساختار و عدم وجود لینک‌های غیرمجاز
python scripts/audit_secrets.py
```
