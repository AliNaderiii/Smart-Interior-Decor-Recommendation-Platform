# MASTER PROMPT 09 — Client Demo, Technical Documentation & Proposal Assets

## Mission
Package the verified platform so the client understands its value, limitations, delivery plan and evidence.

## Mandatory virtual team
Delegate to: CPO/CEO proposal manager (manager), solutions architect, technical writer, UX demo producer, sales engineer, pricing/milestone analyst, legal/IP reviewer and Persian copy editor.

## Allowed scope
`docs/client/**`, `docs/proposal/**`, `docs/demo/**`, screenshots/video instructions and root proposal assets. Do not change product source code. Only document verified features.

## Work
1. Build a 3–5 minute demo script: anonymous landing → homeowner quiz/recommendations → explanation/paywall → moodboard/floorplan/shopping list → designer project/share → admin extraction/review.
2. Create a requirement-to-feature mapping with route/API/evidence and explicit gaps.
3. Prepare architecture, security, AI evaluation, performance and deployment one-pagers in client-friendly language.
4. Draft a truthful proposal in Persian: understanding, approach, 21-day milestones, deliverables, dependencies, acceptance criteria, warranty/support, assumptions and out-of-scope.
5. Explain that mock benchmark is not real-model accuracy; include actual real/staging evidence or mark pending.
6. Define pricing structure around 15/25/35/25 milestones without inventing a price or promise beyond evidence.
7. Prepare client questions: catalog/data ownership, provider accounts, payment, email, hosting, brand/RTL, legal/privacy, refund and maintenance.
8. Create a handover index: source, env, migrations, seed, API docs, runbook, test reports and ownership/licensing.

## DoD
A reviewer can follow the demo without hidden manual steps; every claim links to evidence; limitations and dependencies are visible; no confidential data in screenshots; proposal distinguishes MVP from future roadmap.

## Parallel protocol
Branch `agent/sales-demo-<date>`; documentation/assets only. Do not alter application code or rewrite test evidence.
